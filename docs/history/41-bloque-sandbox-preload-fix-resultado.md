# Bloque sandbox-preload-fix — webpack bundle content preloads

**Status:** ✅ Cerrado 2026-05-15
**Commit:** `a0f092d`
**Version:** 1.4.4 (patch)
**Tiempo efectivo:** ~1h
**Deps nuevas:** ninguna (webpack ya transitive de @electron-forge/plugin-webpack)
**Tests nuevos:** 0 (build-tooling fix, sin asserts)

## Origen — bug descubierto en smoke visual del HUD

Durante el smoke visual del Identity HUD (v1.4.3), page console mostró:

```
Unable to load preload script: .../oz-browser/browser/preload-content.js
Error: module not found: ./site-templates
```

Investigación reveló que **los sandboxed preloads de Electron 42 fallan silenciosamente cuando hacen `require()` de archivos siblings**. Afecta:

- `preload-content.js` → require('./site-templates') — auto-fill + auto-save + TOTP del bloque J
- `preload-fingerprint.js` → require('./preload-fingerprint-script') — FP UA + canvas/audio/webgl spoofs del 1.9b

**Sin estos preloads las features core del producto (auto-login a 50 IG accounts + anti-detect fingerprint) están silentemente rotas.**

## Decisión: webpack bundle preload entries

Considerado:

1. **Inline siblings en cada preload** — descartado porque site-templates.js es 314 LOC + preload-fingerprint-script.js es 266 LOC → pushea preloads sobre LOC budget + duplicación.
2. **electron-forge plugin-webpack entryPoints multi-preload** — descartado porque el plugin es renderer-process oriented (cada entryPoint espera html target).
3. **Standalone webpack bundle script** — ELEGIDO. Pequeño script, usa webpack programáticamente (ya instalado como transitive dep), output a `.bundled/`, npm hooks `prestart`/`prepackage` para invocación automática.

## v1.4.4 — implementación

### `scripts/bundle-preloads.js` (NEW, ~100 LOC)

```js
const webpack = require('webpack')
const PRELOADS = [
  { entry: './browser/preload-content.js', name: 'preload-content' },
  { entry: './browser/preload-fingerprint.js', name: 'preload-fingerprint' },
]
const config = {
  target: 'node',
  entry: { ... },
  output: { path: 'browser/.bundled', filename: '[name].bundled.js', libraryTarget: 'commonjs2', iife: true },
  externals: { electron: 'commonjs2 electron' },
  optimization: { splitChunks: false, runtimeChunk: false },
}
webpack(config, (err, stats) => { ... })
```

Auto-stamped output con banner `// AUTO-GENERATED by scripts/bundle-preloads.js — DO NOT EDIT`.

**Output sizes:** preload-content.bundled.js ~22.2 KiB (incluye site-templates 314 LOC) + preload-fingerprint.bundled.js ~15.3 KiB (incluye preload-fingerprint-script 266 LOC).

### Wire-up

- `package.json` scripts: `prestart`, `prepackage`, `bundle:preloads` (manual)
- `browser/identity-manager.js` `contentPreloadPath()` → apunta a `.bundled/preload-content.bundled.js`
- `browser/fingerprint-preload-setup.js` `fpPreloadPath` → apunta a `.bundled/preload-fingerprint.bundled.js`
- `.gitignore`: `browser/.bundled/`
- `.prettierignore`: `browser/.bundled`
- `eslint.config.js` ignores: `browser/.bundled/`
- `forge.config.js` `extraResource`: agrega `browser/.bundled` para packaging
