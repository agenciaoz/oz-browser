Welcome to OZ Browser

👤

Identities

Each identity is a fully isolated browser session — its own cookies, storage, login state, and extensions.

  • Default identity — your main session, ships with Chrome Web Store extensions enabled.
  • Custom identities — one per persona / account. Switch from the sidebar; tabs remember which identity they belong to.
  • Per-identity color stripe on every tab so you never confuse them.
🗂️

Workspaces & Vault

Workspaces group sessions per project; the encrypted vault stores credentials safely on your Mac.

  • Workspaces — Excel-like grouping. Switch to snapshot the current set of tabs and load a different one.
  • 🔐 Vault — AES-256-GCM encrypted account store. Master key in Keychain. Auto-fill on login pages.
  • ⏱ Time Machine — daily encrypted snapshots of your entire setup. Restore any time.
🌐

Proxies, Fingerprint & Automation

Antidetect that goes beyond Ghost Browser: per-identity fingerprint + GeoIP coherence + headless automation.

  • 🌐 Proxies — assign per-identity / workspace. Auto-disable on health failure. Oxylabs sticky-session template built-in.
  • FingerprintEngine "Ghost+" — 11 vectors spoofed consistently per identity (UA, screen, timezone, canvas, WebGL).
  • MCP server — control OZ from any LLM agent. Toggle on in Settings → Automation.
